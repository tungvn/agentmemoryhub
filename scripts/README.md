# macOS wake hook

Keeps the Cloudflare tunnel alive across sleep/wake.

## Why

When the Mac sleeps (lid close or idle), Docker Desktop freezes its Linux VM. On
wake the container's network sockets are stale and `cloudflared` may not recover
on its own — the local ports keep working but the public tunnel stays dead until
the container is restarted.

Running cloudflared on `--protocol http2` (see `start-cloudflared.sh`) handles
most cases, but a frozen-VM wake can still leave the connection in a zombie state.
This wake hook is the deterministic safety net: it restarts the container on every
wake so the tunnel always comes back.

## Install

From the repo root:

```sh
sh scripts/install-wakeup.sh
```

This will:

1. Install [`sleepwatcher`](https://www.bernhard-baehr.de/) via Homebrew (if missing).
2. Copy `wakeup.sh` to `~/.agentmemoryhub/wakeup.sh`.
3. Write `~/.agentmemoryhub/config` with your repo path and docker binary.
4. Bridge `~/.wakeup` → the installed hook (sleepwatcher runs `~/.wakeup` by default).
5. Start `sleepwatcher` as a login service via `brew services`.

Requirements: macOS, [Homebrew](https://brew.sh), and Docker Desktop.

### Custom install directory

The default home is `~/.agentmemoryhub`. Override it:

```sh
AGENTMEMORYHUB_HOME="$HOME/.config/agentmemoryhub" sh scripts/install-wakeup.sh
```

## How it works

- `sleepwatcher` runs `~/.wakeup` on wake.
- `~/.wakeup` calls `~/.agentmemoryhub/wakeup.sh`.
- `wakeup.sh` reads `~/.agentmemoryhub/config`, waits up to ~60s for the Docker
  daemon to resume, then runs `docker compose restart agentmemory`.

## Verify

Close the lid for a minute, reopen, then:

```sh
cat ~/.agentmemoryhub/wakeup.log
docker compose logs --tail=20 agentmemory | grep "Registered tunnel"
```

You should see a fresh `restarting… done` entry and the tunnel re-registered on
`protocol=http2`.

## Uninstall

```sh
brew services stop sleepwatcher
rm -rf ~/.agentmemoryhub
# remove the agentmemoryhub line from ~/.wakeup (or delete the file if unused)
```

## Config reference

`~/.agentmemoryhub/config` (regenerated by the installer):

| Key           | Meaning                                          |
| ------------- | ------------------------------------------------ |
| `PROJECT_DIR` | Path to the repo (where `docker-compose.yml` is) |
| `DOCKER`      | Path to the `docker` binary                      |
| `LOG`         | Wake-hook log file                               |
